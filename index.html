О проекте

Что такое ТвойВуз?

Суть платформы

ТвойВуз — это платформа из двух компонентов: VK-бот для студентов (уведомления, заявки, расписание прямо в ВКонтакте) и веб-панель для IT-отдела (управление, мониторинг, тикеты).

✔️ Результат

Единая экосистема с открытым кодом, задеплоенная в Docker, с бесплатным использованием для любого вуза.

FastAPI React 18 PostgreSQL Docker JWT

Проблема, которую мы решаем

Современные российские вузы сталкиваются с системными проблемами коммуникации:

  • Уведомления теряются — студенты не получают важные сообщения от деканата вовремя
  • Заявки через бумагу — бюрократические процессы занимают дни вместо минут
  • Расписание не актуально — изменения доходят до студентов с опозданием

Возможности

Что умеет платформа

Шесть ключевых функций, закрывающих основные потребности вуза

Уведомления

Рассылка сообщений студентам группы или всему курсу через VK Bot API. Целевые и массовые оповещения.

Заявки

Подача и отслеживание статуса заявок через бота. Студент видит прогресс в реальном времени.

Расписание

Синхронизация через JSON/CSV, мгновенный доступ в VK. Актуальное расписание всегда под рукой.

Структура вуза

CRUD управление факультетами, кафедрами и группами. Гибкая настройка иерархии через веб-панель.

Мониторинг

Графики активности, статус бота и ключевые метрики в реальном времени на дашборде IT-отдела.

Тикеты поддержки

Прозрачная система обработки обращений с историей. Канал связи IT-отдела с пользователями.

Пресс-релиз · 30 марта 2026

На встрече команда из 5 разработчиков определила архитектуру системы и распределила зоны ответственности. В ходе мозгового штурма было принято решение использовать FastAPI в качестве основного бэкенда и React с MUI для веб-панели.

Дмитрий Филков был выбран тимлидом и взял на себя ответственность за аутентификацию и архитектурные решения. Никита Машнин займётся разработкой VK-бота, Денис Пикуль — DevOps и базой данных, Мария Пиндюрина и Александра Борунова — фронтендом.

Команда договорилась использовать недельные спринты с еженедельными синхронизациями и трекингом задач через GitHub Issues.
